【血脉原文】
待补玩家原文。已知要素：清风之念层数、清念/残脉双形态、每 5 回合切换期、通用被动。

【技能 1】清翎覆尘（翼 / 变化 / 3PP / 先手+7 / 必中）
清翎之翼，覆尘万物。本技能免疫PP删除和额外PP损失，仅能被轻风散魂回复。【清风之念<3或无清念】2回合内每回合获得护盾（200+40%已损HP），免疫后手伤害。【清风之念≥3且清念状态】净化自身，回复全部精力，其他技能回复30%PP，终止对方所有回合效果，12回合内免疫异常和负面强化。【首次使用】双方所有技能视为自身主属系，持续(2+技能数×2)回合。【梦境环境下】先手值反转为后手-7。

【技能 2】轻风散魂（翼 / 变化 / 8PP / 先手+3 / 必中）
轻风拂面，魂散九天。闪避对方本回合后手技能和下回合非必中技能。删除对方全体(10+4×清风之念)%的PP，最高25%。【清念 1-2层】3回合内连动：对方非翼系技能额外损失2PP，翼系额外损失1PP；每回合吸取对方精力并限伤150。【清念 3-4层】所有效果必中，额外删除PP。【≥5层】清除所有清风之念，回复清翎覆尘2PP，切换到残脉状态。【残脉状态】清空本技能PP直到重新进入清念。

【技能 3】残念余梦（冰 / 变化 / 6PP / 先手-1 / 必中）
残念化梦，余韵悠长。强制清除场上所有天气，召唤梦境1回合。返还上次受到的伤害，追加固定伤害（基于双方速度差×残风临霜已损PP×空PP技能数），上限600。后手时令对方沉睡（自身无法换宠直到对方解除）；沉睡失败则删除对方全体1PP。【残脉】固伤增幅至(1.8+当前HP比例)倍，上限1000，有抗性时分4段结算。【清念】使用后清空本技能PP直到重新进入清念。

【技能 4】残风临霜（冰 / 变化 / 4PP / 先手+4 / 必中）
残风凛冽，临霜万物。本技能免疫PP删除，仅能被清翎覆尘回复。冰冻对方：成功则驱逐对方，对下一个上场宠物施加睡眠（睡眠失败则造成999固伤分3段）。冰冻失败则删除对方使用次数>6的技能PP，若对方空PP技能≥2则驱逐。结算后自身速度降低30%，获得基于速度差和已损HP比例的护盾。若未携带清翎覆尘则进入残脉状态。

【技能 5】清念沉脉（翼 / 变化 / 6PP / 先手+3 / 必中）
清念沉心，脉动万物。强制清除双方所有强化等级，对敌方治疗（清除的强化总级数×60HP）。若治疗量低于240则额外删除对方上次使用技能5PP。回复自身全体技能3PP。消耗本技能全部PP，进入清念状态（持续1+消耗PP数回合）。状态结束后回复（双方损失PP总数×0.5）点PP，并令对方4回合内威力技能伤害降低30%（最大50%），变化技能先手值-1。
