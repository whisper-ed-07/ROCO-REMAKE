【血脉原文】
待补玩家原文。已知要素：固伤反转治疗、禁暴与 PP 回复封锁、克制减伤、分段后回复。

【技能 1】创世之能（普通 / 变化 / 3PP / 先手+6 / 必中）
不灭之威，创世奇迹。【被动】始终免疫睡眠、冰冻、恐惧。【主动】释放后3回合内：双方速度提升10%，自身输出提升25%；每回合吸取对方全体2PP回复自身；对方PP最少的技能额外消耗1PP。第1回合回复全部精力值并无视对方后手效果；第2回合强制重置双方所有强化并回复首格技能全部PP；第3回合若自身HP低于30%则回复70%已损精力。本技能PP耗尽后获得永久全异常免疫。本技能免疫PP删除和回复效果。

【技能 2】逆流而行（水 / 物理 / 威力135 / 2PP / 先手+4 / 必中）
时间倒流，逆转法则。135威力水系物理攻击，必中。①回溯3回合前的HP状态，追加差值等量固定伤害。②恢复己方场下第2只宠物全体技能1PP（若创世之能PP为空则恢复2PP）。③本技能PP=0时失去属系变为普通系，按累计使用次数触发：第1次使用PP=0时，追加9999点固定伤害，清空对方全体PP，回复自身全体1PP；第2次使用PP=0时，回复自身全体3PP和30%HP。④创世之能PP为空时，清除并锁定双方所有强化6回合。本技能免疫PP删除和回复效果。

【技能 3】灭世之威（武 / 物理 / 威力70 / 12PP / 先手+1 / 必中）
灭世陨落，威能震世。70威力武系物理攻击。先手时：额外追加对方最大HP30%的固定伤害并施加恐惧。后手时：必中必爆，删除对方全体(1+自身负面强化数)PP；若伤害被抵抗则清空对方上次使用技能的全部PP。若处于创世之能回合内：威力提升至170，物攻按+3级计算，回复200HP。若创世之能PP为空、有2个技能PP为空、且剩余PP总数<8时：追加9999固伤并回满所有技能PP。

【技能 4】覆体魂衣（普通 / 变化 / 8PP / 先手+3 / 必中）
覆衣于身，以魂护体。【常规】消耗15%当前HP（不会致死），获得：2回合内超过自身15%最大HP的伤害降至80点；4回合免疫所有异常状态；双防提升2级；净化自身并反转所有负面强化为正。创世之能PP为空时：不消耗HP，回复400HP，1回合内减少70%所受伤害，倒置对方1回合治疗（治疗变为伤害），4回合内每回合回复20%HP并为PP最低的技能回复1PP，但每回合随机降低自身1项强化。若场上有天气则每回合额外回复120HP和全体1PP。

【技能 5】重衍纪元（普通 / 变化 / 1PP / 先手-7 / 必中）
纪元重衍，万物复苏。若本回合先手且未受到任何伤害：回复己方全体宠物（含场下）所有技能2PP。否则：将双方全体宠物的PP回退至最近24回合内的最低值，随后自身立即死亡。若自身其他技能有PP为空则无法使用。本技能PP不为0时自身所有输出降低40%。本技能免疫PP删除和回复效果。
