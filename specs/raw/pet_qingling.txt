【基础信息】
名称：清灵
系别：幽灵（ghost）
定位：输出 / 干扰（待玩家确认）
等级：100
种族值：HP 149 / 物攻 152 / 物防 128 / 魔攻 151 / 魔防 129 / 速度 132
血脉：清念灵体
技能数：5

【血脉原文】
获得（5*双方阵亡宠物数）%减伤，max=（60-双方存活宠物数）%，每次双方同时使用变化技能或威力技能时，自身获得（双方使用技能先手值）点"微灵"印记，max=（100+双方技能PP为空数*20）（此处max仅代表此项效果所获取的上限）

血脉①（使用威力技能后）
    ⑴ 若本技能先手：删除对方全体技能1PP；追加固伤 (30 + 双方正负面强化数×20 + 自身8%最大精力)
    ⑵ 若本技能后手：倒置对方下次治疗（多段治疗取最高）；删除对方先手使用技能3PP
血脉②（使用变化技能后）
    回复 200 精力；若使用技能 PP≤4：回复全体技能 2PP + 额外倒置对方治疗 2 回合

【技能 1】微灵封体（幽灵 / 变化 / 1PP / 先手+7 / 必中）
净化回复全部精力与全体技能(3+使用前精力比例)PP，本局全局屏蔽限伤/减伤/护盾/反弹；永久免疫异常与负面强化，1回合免疫威力伤害；6回合每回合赋予双方(5+已损精力/50)点微灵印记(max15)。

【技能 2】万念俱灰（幽灵 / 物理 / 威力150 / 6PP / 先手+3 / 必中）
免疫删除与除微灵封体外所有回复PP。实际威力=损失PP数×(150+微灵印记)，max500(首格PP=0时max1000)；输出首格PP>0时≤0.9×对方最大精力、PP=0后≥0.3×自身最大精力；回150精力+6回合免疫异常；先手追加强化数固伤+重置双方强化(首格PP=0必暴击)，后手双方回复(威力×1.1 max400)(首格PP=0清空对方先手技能PP)。

【技能 3】封灵千噬（幽灵 / 魔法 / 威力70 / 8PP / 先手+4 / 半必中）
半必中。实际威力=70+万念俱灰威力×0.2(max150)。连续3回合：每回合免疫异常+10微灵+100护盾(首格PP=0回100精力)+对方使用技能额外损失1PP；首回合免疫对方后手效果+删对方使用技能1PP+给予封灵印记(换下失效)(先手必暴击必中)；次回合追加对方上回合输出×0.6物理伤害；末回合回30%精力+全体1PP，消耗太虚灵威所有PP尝试清除对方全体PP(仅太虚灵威PP=8可触发，概率=5%+已损PP占比%)。

【技能 4】太虚灵威（幽灵 / 变化 / 8PP / 先手+1 / 半必中）
半必中。未命中时仅删除对方全体技能2PP。恐惧对方：失败则删对方全体2PP，令对方3回合内使用额外消耗1PP且无法换宠；微灵印记≥200：额外删除对方上次使用技能6PP，此后若双方PP空技能数≥4则追加9999点固定伤害。

【技能 5】万古遗恨（幽灵 / 物理 / 威力20 / 20PP / 先手-5 / 必中）
召唤迷雾天气12回合（失败则强制重置双方强化；成功则追加万念俱灰威力-本威力固伤max349）；微灵印记>300时下回合给予对方本回合双方输出伤害差治疗。
