【技能 1】极尽降华（光 / 变化 / 1PP / 先手+7 / 必中）
光衍至极点，满天降光华。6回合内全场技能视为光系（标记目标翻倍），全场+100%回复与输出，自身免疫异常与负面强化；觉醒首用回满+限伤300；PP被删自动触发；仅特殊效果回复PP。

【技能 2】化念作刃（武 / 物理 / 威力90 / 9PP / 先手+3 / 必中）
以意念为引，作不朽之刃。90威力武系物理。4回合持续：回被删PP技能1PP+30%最大精力+免疫异常驱逐。首回合先手闪避后手非必中（失败倒置强化+删2PP）/后手删先手技3PP+对方PP消耗加速。印记分支：追加固伤/删PP/999斩杀。

【技能 3】极影光幕（光 / 变化 / 6PP / 先手+5 / 命中90 / 半必中）
速变如极影，处处现光幕。回60%精力+10回合闪避一次致命伤害（成功回全体1PP）；净化+5回合免疫+速度提升（上限10%）；4回合叠加护盾（上限100%精力）；对方连续使用同一技能3回合+则PP消耗+2；印记≥2回复+50%。

【技能 4】瞬华若霜（冰 / 物理 / 威力100 / 8PP / 先手-1 / 必中）
瞬影现光华，似若降华霜。威力=100+20m+0.05×速度。冰冻：成功删对方全体1PP+2回合对方治疗-50%；失败回全体1PP+倒置对方正面强化。m>3冰冻成功追加9999固伤+回全体2PP。先手非梦境：2回合先手+4+2段固伤。后手：召唤梦境3回合+梦境下先手值=8+|先手值-8|。m≥4回全体4PP。

【技能 5】炽光若焰（火 / 特殊 / 威力120 / 8PP / 先手+1 / 命中90 / 半必中）
炽热似神光，宛如焚天焰。威力=120+0.1×魔攻。烧伤成功追加2~4段70~100固伤；失败清空自身PP与对方同格技能PP（12回合免疫回复）。4回合召唤锁定瞬华环境：光系+15%速度、先手出招回100精力、被抵抗追加30%固伤。
