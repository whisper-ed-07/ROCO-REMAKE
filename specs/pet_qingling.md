## 2. 血脉：清念灵体

### 2.1 设计（原文）

获得（5×双方阵亡宠物数）% 减伤，max =（60−双方存活宠物数）%；每次双方同时使用变化技能或威力技能时，自身获得（双方使用技能先手值）点「微灵」印记，max =（100 + 双方技能 PP 为空数×20）。

- 使用威力技能后：先手 → 删对方全体 1PP + 固伤（30 + 双方正负强化数×20 + 自身 8% 最大精力）；后手 → 倒置对方下次治疗 + 删对方先手使用技能 3PP。
- 使用变化技能后：回复 200 精力；若该技能 PP ≤ 4 → 全体技能 +2PP、额外倒置对方治疗 2 回合。

### 2.2 实现（代码级）

- `onTurnStart`：`dr = min(5 × 阵亡数, 60 − 存活数)`；`damageReduction = dr`、`damageReductionTurns = 1`；`dr ≤ 0` 时不赋值（旧减伤在本回合末自然到期）。
- `onSkillUse(status)`：`doHeal(pet, 200)`；`skill.pp ≤ 4` 时全体 `pp += 2`、`invertHealing(target, 1.0, 2)`。
- `onSkillUse(power)`：先手 → `deletePP(target, -1, 1)` + `doFixedDamage(30 + 20×双方强化数 + floor(maxHp×0.08))`；后手 → `invertHealing(target, 1.0, 1)` + 对 `target.lastUsedSkillId` 扣 3PP。
- 微灵印记（在 `resolveTurn` 内）：双方本回合技能类别相同（同为 status 或同为 power）时，给持有「清念灵体」的一方加 `pSkill.priority + aSkill.priority`，上限 `100 + 双方空 PP 技能数×20`。

### 2.3 偏差

- **M1**：印记增量取的是技能**基础先手值**，不含 `priorityOverride`、迷雾 +1、梦境反转等修正；原文为「双方使用技能先手值」。
- **M2**：`sk_ql_1` 的 6 回合印记按**各自**已损精力计算；原文为「自身已损精力」（施放者）。
- **M6**：`sk_ql_1` 回血用 `maxHp − hp`，忽略 `maxHpBonus`。

## 4. 逐技能

### 4.1 微灵封体（sk_ql_1）

- **设计**：净化 + 回满精力 + 全体技能回 (3 + 使用前精力比例) PP；本局全局屏蔽限伤/减伤/护盾/反弹；永久免疫异常与负面强化，1 回合免疫威力伤害；6 回合每回合给双方 (5 + 已损精力/50) 微灵印记（单次上限 15）。
- **实现**：`doHeal(maxHp − hp)`；`ppHeal = ceil(3 + hp/maxHp)`；写入 `gameState.banEffects = {shield, dmgReduction, damageCap, reflect}` 并清空双方对应字段；`statImmunity = true` + 8 种异常免疫；`immunePowerDamage` 1 回合；对双方各注册 6 回合印记 tick。
- **偏差**：M2、M6。

### 4.2 万念俱灰（sk_ql_2）

- **设计**：威力 = 损失 PP 数 ×(150 + 微灵)，上限 500（首格 PP=0 时 1000）；首格 PP>0 时伤害 ≤ 0.9×对方最大精力，PP=0 后 ≥0.3×自身最大精力；回 150 精力 + 6 回合免疫；先手追加 30% 固伤并重置双方强化；后手双方回（威力×1.1，上限 400），首格 PP=0 时清空对方先手技能 PP。
- **实现**：`lost = max(1, 6 − 当前PP)`（硬编码 6）；`ctx.doDamage(..., {guaranteedCrit: firstZero, maxDamage: 0.9×t.maxHp, minDamage: 0.3×u.maxHp})`；先手分支 `doFixedDamage(floor(dealt×0.3))` + 六维清零；后手分支双方 `doHeal(min(400, floor(power×1.1)))`。
- **偏差**：M3（硬编码 6，若 maxPp 改动则成长曲线错位）。

### 4.3 封灵千噬（sk_ql_3）

- **设计**：半必中；威力 = 70 + 万念俱灰威力×0.2（上限 150）；连续 3 回合：每回合免疫异常 + 10 微灵 + 100 护盾 + 对方 PP 额外消耗；首回合免疫后手 + 删 1PP + 封灵印记；次回合追加对方上回合输出×0.6 物理伤害；末回合回 30% + 全体 1PP，太虚灵威满 PP 时按概率清空对方全体 PP。
- **实现**：伤害只结算一次；3 回合免疫用 `addTurnEffect`；`t.skillPPCostMult += 1` 并注册 3 回合递减；`t.qlSealMark = true`；次/末回合效果各用一个 turnEffect；太虚爆发概率 `5 + floor(已损PP/总PP×100)`。
- **偏差**：M4（「连续 3 回合」仅首次结算直接伤害；`qlSealMark` 只写不读，全文件无消费点）。

### 4.4 太虚灵威（sk_ql_4）

- **设计**：半必中；未命中仅删对方全体 2PP；恐惧失败 → 删 2PP + 3 回合 PP 额外消耗且禁换宠；微灵 ≥ 200 → 额外删对方上次技能 6PP，双方空 PP 技能 ≥ 4 时追加 9999。
- **实现**：`applyStatus(t, 'fear')` 失败分支删 2PP、`skillPPCostMult += 1`、`switchLocked = true` 并注册 3 回合效果（每回合重新上锁、到期解锁）；`onMiss` 删 2PP。

### 4.5 万古遗恨（sk_ql_5）

- **设计**：召唤迷雾 12 回合；失败（环境在场）重置双方强化；成功追加（万念俱灰威力 − 20）固伤，上限 349；微灵 > 300 时下回合给予对方本回合双方输出差值的治疗。
- **实现**：`ctx.setWeather('mist', 12)`；失败 → 六维清零；成功 → `doFixedDamage(min(349, wjPower − 20))`；随后结算 20 威力伤害；`ml > 300` 时注册 1 回合效果，给对方 `doHeal(max(0, 自身输出 − 对方输出))`。

## 6. 验证清单（建议断言）

- [ ] 减伤公式：阵亡 2、存活 2 → 10%，且不叠加。
- [ ] 同类别出招（双变化 / 双威力）→ 印记 += 双方先手值；异类别 → 不加。
- [ ] 印记上限 = 100 + 空 PP 技能数×20（每次触发后重算）。
- [ ] 微灵封体后：护盾、限伤、减伤、反弹全部失效，且不可恢复。
- [ ] 万念俱灰首格 PP=0 时伤害 ≥ 0.3×自身最大精力，且必定暴击。
- [ ] 太虚灵威未命中只删 2PP，不施加恐惧。

## 附录 A：旧规格与裁定记录（原 `specs/pet_qingling.md` 摘要）

**迷雾天气（A1）**：属天气，可覆盖其他天气、不可覆盖环境；幽灵技能先手 +1；双方行动前/后各 80% 概率混乱；持续 12 回合。

**半必中（A2）**：仅对方具有「必定闪避」时不命中，其余必中。

**首格技能（A3）**：技能顺序可局外调整，首格 = 排序后第 1 格，可任意技能。

**永久限制（A7）**：微灵封体的屏蔽为本局剩余时间。

**太虚概率（A9）**：概率 = 5% + 已损 PP 占全部 PP 的百分比。

**万古遗恨（A10）**：末句为治疗对方，与血脉倒置治疗不冲突。
