# 新增宠物流程

1. **收录原文。** 将玩家最终文本原样保存为 `pets/<宠物名>.txt`，确认属性、种族值、技能、血脉和实际影响的目标。
2. **整理机制。** 用[模板](PET_TEMPLATE.md)写 `pets/<宠物名>.md`。记录公式、取整、上限、触发顺序、免疫、PP 来源和换宠边界。遇到歧义或引擎能力缺口，先列出问题供玩家裁定。
3. **实现与注册。** 按 [src/pets](../src/pets/) 中同类机制实现技能与血脉，在 [catalog.js](../src/data/catalog.js) 注册。接入 [pet-text.cjs](../scripts/pet-text.cjs) 的原文映射，构建清单将新文件置于注册表之前。技能使用统一伤害、防控、PP 和回合效果接口。
4. **验证与交付。** 构建后核对局内文字与 TXT、面板和实际结算。跑静态检查、至少一组对应每个关键机制的定向回归，以及现有对战矩阵。原文、机制文档、实现和新增测试按本次范围一并提交。

机制复核以玩家原文和最新裁定为准。记录仍未实现或依赖未决规则的部分。构建与测试命令见[开发手册](../AGENTS.md)。
