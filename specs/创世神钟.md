## 2. 血脉：不灭魂体

### 2.1 设计

原文缺失。从代码可还原：固伤部分转化为治疗；受到威力伤害时禁用对方暴击并封锁其 PP 回复；受到克制伤害时减伤 40%；每段伤害后按递减比例回复已损精力。

### 2.2 实现（代码级）

- `onBeforeDamage(pet, dmg, type, attacker, ctx)`
  - `fixed`：先 `doHeal(floor(dmg×0.3))`，再照常扣血（等于固伤 30% 被治疗抵消）。
  - `power`：给攻击方 `preventCritNext = true`、`blockPPRecovery = true`；若克制（`eff ≥ 2`）则 `dmg × 0.6`（受 `banEffects.dmgReduction` 约束）。
- `onAfterDamageSegment(pet, segIdx, ctx)`：第 n 段后回复 `(30 − 4n)%` 已损精力（n=1 → 26%，n=7 → 2%）。
- `onTurnStart`：携带 `sk_cszn` 时永久免疫 freeze/sleep/fear；`sk_cszn.pp === 0` 时免疫 8 种异常并清除当前异常。

### 2.3 偏差

- **M1**：克制减伤用 `attacker.skills.find(s => s.pp < s.maxPp)?.element` 猜测本次攻击系别——取的是「第一个 PP 未满的技能」，与实际出招无关。
- **M2**：`blockPPRecovery` 每回合开始被清空，但技能里大量直接 `s.pp++` 不受其约束（见 AGENTS §13 遗留）。

## 4. 逐技能

### 4.1 创世之能（sk_cszn）

- **设计**：被动免疫睡眠/冰冻/恐惧；主动 3 回合：双方速度 +10%、自身输出 +25%；每回合吸对方全体 2PP 回复自身；对方 PP 最少技能额外 −1PP；第 1 回合回满并无视后手效果；第 2 回合重置双方强化 + 回满首格；第 3 回合 HP < 30% 回 70% 已损；PP 耗尽获得永久全异常免疫。
- **实现**：`creationTurn/creationActive` 记状态；`spdMod += 0.1`（双方）、`dmgMod += 0.25`；3 回合 turnEffect 内每回合 `deletePP(opp,-1,2)`、自身每技能 +1PP、对方最低 PP 技能 −1；第 1/2/3 回合分别回满、重置强化 + 首格满 PP、回 70% 已损；到期时若 `sk_cszn.pp === 0` 则永久免疫 7 种。
- **偏差**：**M3** `spdMod/dmgMod` 无到期回收；**M4**「无视对方后手效果」未实现。

### 4.2 逆流而行（sk_nlex）

- **设计**：135 水系物理必中；回溯 3 回合前 HP 差追加等量固伤；场下第 2 只回全体 1PP（创世之能 PP 空则 2PP）；本技能 PP=0 时变普通系，第 1 次触发 9999 + 清空对方 PP + 回 1PP，第 2 次回 3PP + 30% HP；创世之能 PP 空时清并锁强化 6 回合。
- **实现**：`saveSnapshot()` → `ctx.doDamage` → `doFixedDamage(|getSnapshotHPDiff(3)|)`；场下第 2 只 `+1PP`（创世 PP=0 → `+2`）；`skillUseCounts` 计数；PP=0 → `element = 'normal'` 并触发 9999 / 回 3PP + 30% HP；创世 PP=0 → 六维清零 + `statLocked` 6 回合。
- **偏差**：**M5** 快照只在施放时 push，「3 回合前」实为「3 次施放前」。

### 4.3 灭世之威（sk_mszw）

- **设计**：先手 → 追加对方最大 HP 30% 固伤 + 恐惧；后手 → 必中必爆、删对方 (1+自身负面数)PP，被抵抗则清空对方上次技能 PP；创世回合内 → 威力 170、物攻按 +3、回 200；终焉条件 → 9999 + 回满。
- **实现**：`pendingFirstMove` 判先后（原为 `isPlayerTurn`，已修）；先手 `doFixedDamage(0.3×t.maxHp)` + `fear`；后手 `guaranteedCrit` + `deletePP(1+负面数)` + 被抵抗时清 `lastUsedSkillId`；创世回合内再 `doDamage(170, atkStageOverride:3)` 并关闭 `creationActive`；终焉条件 `cszn.pp===0 && 空PP≥2 && 总PP<8`。
- **备注**：终焉条件的「2 个技能 PP 为空」按当前 `filter(pp===0).length >= 2` 实现。

### 4.4 覆体魂衣（sk_fthy）

- **设计**：常规 → 扣 15% 当前 HP（不致死）、2 回合限伤（超 15% 最大 HP 的伤害降为 80）、4 回合免疫、双防 +2、净化并反转负面；创世 PP 空 → 不扣血、回 400、1 回合减伤 70%、倒置对方 1 回合治疗、4 回合每回合回 20% + 最低 PP +1、随机 −1 强化；有天气时每回合额外 120 + 全体 1PP。
- **实现**：`csznEmpty` 分支按设计；常规分支扣血、`setDamageCap(0.15×maxHp, 80, 2)`、4 回合免疫；双防 +2、`status=null`、负强化取绝对值；天气分支只在施放时执行一次（回 120 + 全体 +1PP）。
- **偏差**：**M6** 「有天气时每回合额外回复」实现为施放时一次。

### 4.5 重衍纪元（sk_cyjy）

- **设计**：其他技能有空 PP → 不可用；先手且未受伤 → 己方全体（含场下）回 2PP；否则 PP 回退到最近 24 回合最低 + 自身立即死亡；PP 不为 0 时自身输出 −40%。
- **实现**：`hasEmpty` 直接 `return`（不消耗回合效果）；未受伤判断 `user.hp < user.maxHp`；先手分支遍历己方队伍 +2PP；否则遍历双方队伍，逐技能取历史最低 PP，然后 `user.hp = 0`；`outputReduction = 40` 一次性赋值。
- **偏差**：**M7** `hp < maxHp` 是「当前是否满血」而非「本回合是否受伤」（OPEN-QUESTIONS Q1）；`outputReduction` 永久，且「PP 不为 0」期间不会因 PP 恢复而归零。
