# 过渡动画设计与验收清单（2026-11-11）

方案基线 `43f0e6e`。以玩家指定的 10 月 26 日版式、色彩和原有文案为基础，覆盖页面切换、选宠、弹层和战斗反馈。逐招和多段演出另属后续设计。A/B/C 三阶段已有实现与 DOM 回归，见[实施记录](../2026-11-11-motion-implementation/README.md)。

## 设计值

| 场景 | 方案 |
|---|---|
| 启动与导航 | 启动层淡出 360ms。页面淡入约 200ms、上移 8px。首次进战斗约 200–240ms。 |
| 控件 | 支持悬停的设备启用悬停反馈。按钮按压 120ms、缩至 0.985。选宠/装备约 140ms，仅改当前控件。配置区首次展开约 180ms，排序时继续操作。 |
| 弹层 | 普通弹层与换宠面板开 180ms、关 140ms。换宠面板保持水平居中。结果层开 220ms、关 140ms。 |
| 战斗 | 精力与护盾实条 280ms，失血残影延后 80ms、约 420ms 追平，受击约 180ms、最大偏移 4px，漂字约 700ms，新宠入场约 180ms。 |

## 当时的实施约束

- A 负责页面和选宠。同步挂载目标 DOM，只有导航重播入场。选宠局部更新，保留 1–6 只、状态、焦点和配置顺序。
- B 负责技能详情、表单、换宠、逃跑和结果弹层。保持 Esc、Tab 循环、关闭回焦与一次提交。动画结束校验事件目标，快速重开、导航、元素脱离和事件缺失时清理捕获的旧节点。
- C 负责精力、护盾、漂字及换宠。按战局、阵营及宠物实例匹配视觉状态，新宠直接读真实比例。无变化的刷新保持进度，退出或开新局清除旧视觉回调，保持读日志位置及技能条横滚。
- 减少动态效果时停止位移、缩放、背景循环和视觉等待。原本的 20 秒行动计时与 800ms 换宠/空过处理由玩法决定。结算、替补、保存及业务回调继续同步。装饰过渡只清理表现。
- 当时 Terra 独占主 HTML 写入并补定向测试，Luna 按清单复核，Codex 审核各阶段变更。当前开发入口见[开发手册](../../AGENTS.md)。

## 实机观察清单

1. 以桌面 1440×900、窄屏 390×844，分别在深浅主题走完启动、菜单、双方选宠、开战、换宠、结果及返回。
2. 验证长技能详情、表单及配置的键盘焦点、手机横滚、正文滚动、弹层居中与关闭后的回焦。0 PP 时尝试详情与施放。
3. 播放观察裁切、闪屏、重复入场、瞬间满血、己方或后台漂字错位。连续失血、回血、主动换宠、替补和退出再开局各测一次。
4. 开启减少动效并在动画播放中切换，连续快速开关弹层，检查旧遮罩、事件及焦点。观察实际动画帧或录屏，记录浏览器、尺寸、主题及结果。
