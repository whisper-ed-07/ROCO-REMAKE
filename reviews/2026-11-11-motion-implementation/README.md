## B：弹层开合与清理

- 为技能详情、表单、逃跑、换宠和结果层补进入/退出过渡；共享节点级关闭状态，快速重开和导航强制清理旧节点及回调。
- 详情关闭期间保留焦点环；原触发器已脱离页面时不回焦。保存、取消、逃跑和结果业务动作保持同步，装饰动画不推进回合或改变计时。
