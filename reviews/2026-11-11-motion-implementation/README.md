- 启动层改为 360ms 淡出，过滤无关结束事件，提供超时清理与减少动态效果的即时清理；清理后回焦菜单。

## B：弹层开合与清理

- 为技能详情、表单、逃跑、换宠和结果层补进入/退出过渡；共享节点级关闭状态，快速重开和导航强制清理旧节点及回调。
- 详情关闭期间保留焦点环；原触发器已脱离页面时不回焦。保存、取消、逃跑和结果业务动作保持同步，装饰动画不推进回合或改变计时。
- 关闭时捕获当前 opacity/transform 并停止入场动画，避免快速关闭被入场动画覆盖；结束或强制清理后恢复临时样式。CSS 提供停止入场的降级规则。
- 独立检查发现的表单节点捕获与存档测试不兼容问题已修复，未删减既有断言。主代理与 Sol 只读审查发现的快速关闭冲突也已修正。
- 前端定向断言覆盖焦点环、重复关闭、快速重开、旧节点事件、缺少结束事件的兜底清理、同页刷新与临时样式恢复。静态 0 错 0 警；存档 3 组、验收 25 项通过；核心 25 项和 16 场矩阵结果与 A 一致。

## C：战斗反馈与局部更新

- 双方 HP 与残影使用同一显示更新逻辑：首次和新宠直接显示真实值，扣血残影最终追平，恢复立即同步残影，无变化刷新不重置过程。护盾条保留原节点更新，归零后清理。
- 实际失血才触发轻受击，漂字精确匹配当前双方对象，后台宠物不再误显示到敌方。退出、重建、新局或减少动态效果变化时清理旧视觉任务。
- 同一战斗重建时恢复未换侧当前显示比例，只有换上的宠物播放入场；保留历史日志阅读位置和技能栏横滚位置。
