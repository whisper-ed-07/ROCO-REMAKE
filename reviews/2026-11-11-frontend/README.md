## 改动

- 大厅改为介绍区与操作入口并列，保留金色 RR 标识；展示实际伙伴/技能数量，增加四位伙伴的技能配置快捷入口。
- 统一桌面、平板、手机的页面宽度和间距；选宠网格随可用宽度变化，管理列表与技能配置行允许文本换行。
- 战场增加明确的敌我标识与日志/行动分区；四技能保留 01→04 单行横向顺序，卡片保留可读宽度，窄屏在技能条内横滚；换宠与挣扎放到独立操作区。
- 技能施放与详情改为两个独立原生按钮；零 PP 仅禁用施放，详情仍可打开。详情正文单独滚动，支持 Esc、关闭回焦和弹窗内 Tab 循环。

- 亮色主题统一面板、表单、天气、日志标签等配色；字体仍沿用用户的中文/英文设置，保留本地回退与减少动态效果偏好。

本次没有修改技能原文、机制、数值或存档格式，所以没有改宠物机制 MD。已比对默认技能/宠物、核心引擎和开战初始化代码块，与基线一致。
